# PetPilot

猫主人的持续照护助理。用一句话记录日常，把事实归到对应的猫，并接续需要补充、纠正和跟进的事项。

当前版本支持猫档案、文字记录、多猫归属、记录纠错、站内提醒、图片与文字说明、就医准备摘要和周回顾。

## 本地启动

运行环境：Python 3.12、Node.js 24，以及随 Node.js 安装的 npm。以下命令从项目根目录开始执行。

先准备后端：

```bash
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

打开新建的配置文件，把访问码占位内容换成自己设置的值。使用自然语言记录前，需要在本机填写模型连接地址、模型名称与访问凭据，并保持网络可用。模型配置留空时只能用于启动与页面检查，不提供自动分猫归档。配置内容保存在本机文件中。

启动后端：

```bash
bash run.sh
```

保留该窗口，另开一个终端，在项目根目录启动前端：

```bash
cd frontend
npm ci
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

打开 <http://127.0.0.1:5173/>，使用自己设置的访问码进入。两个服务窗口均须保持运行；需要停止时分别按 Ctrl+C。

再次启动时，在两个终端分别执行后端与前端的启动命令即可，无需重新安装。前端生产文件可通过 `npm run build` 构建。

## 开始使用

1. 在对话页点击「建猫」，建立两只虚构的猫，例如明月、贝塔。
2. 输入“明月喝了40毫升水，贝塔吃了18克猫粮”，到「记录 → 已确认」核对猫名、数值和单位。
3. 输入“贝塔进食那条改为20克”，核对原记录更新及版本变化。
4. 输入“提醒我给贝塔梳毛，时间稍后补”，再输入“明天下午四点”，到「提醒」核对同一事项的时间。
5. 对缺少猫名的提醒补充“称重提醒归明月”，或在提醒页选择猫；有多个目标时先明确具体事项。

## 使用范围

记录、图片和任务默认保存在本机。后端启动时执行数据库迁移；移动数据时应同时保留数据库与图片目录，并在升级前备份。刷新页面与正常重启不会主动清空记录。「清空数据」属于删除操作。

提醒在站内查看，需要本机服务运行。图片保存原件与文字说明；当前不自动识别图片内容。就医摘要整理已有事实，不提供诊断、处方或真实医院预约。模型处理失败时，保留输入并检查网络与本机配置后重试。
