## 必须问（本轮 3 个，回复"按推荐"即可）

### 问题 1：模型厂商、成本上限与数据出境（D4 + D7）
- 为什么重要：猫健康数据属于个人敏感数据，选哪家模型直接决定数据出不出境、会不会被拿去训练；成本上限决定护栏怎么设。
- 选项：A 国内模型（DeepSeek / Kimi / MiniMax）｜B 国外模型（OpenAI / Claude）｜C 不确定
- 推荐：A 国内模型（首选 DeepSeek）。数据不出境、价格低，与产品隐私红线（R72）一致；每月模型费用上限先设 100 元。
- 不选的后果：选 B 需单独接受数据出境并可能被训练，成本也高 5~10 倍；选 C 则无法定成本护栏，阶段 2 会卡住。

### 问题 2：上线套餐（D9）
- 为什么重要：AGENTS.md 要求阶段 0 必问，影响阶段 4 的资源规格。
- 选项：A 免费体验版（0 元，6 个月可续，每月 3000 资源点，用完即停）｜B 个人版（19.9 元/月，每月 4 万资源点）
- 推荐：A 免费体验版。你的 MVP 是面试演示 + 小范围试用，够用且不会欠费，不够再升级。
- 不选的后果：选 B 每月产生费用；但若预期每天都有人用，B 更稳。

### 问题 3：本轮交付范围（D10）
- 为什么重要：一页纸MVP §8 写"本机稳定运行 + 面试演示 = 收口条件，腾讯云部署后续待核实"，这与工具包默认"阶段 4 上线腾讯云"不同，需要你确认这是本轮的正式范围。
- 选项：A 确认本轮只做到"本机跑通 + 能演示"，腾讯云上线推迟到下一轮｜B 本轮就要部署上线到腾讯云
- 推荐：A。先本机跑通核心闭环、真实模型验收通过，再谈上线，风险最小；腾讯云作为下一轮阶段 4 单独做。
- 不选的后果：选 B 则本轮范围扩大，需提前做部署适配（存储、提醒调度等），验收周期拉长。
