# 第 3-2 阶段开发文档（前端）｜语音 + 响应式打磨 + 发布准备

> 配套：`docs/阶段文档/前端适配声明.md`、前端技术栈手册。
> 本阶段是阶段 3 的最后一个子阶段，做完即"本机可演示 MVP"完整交付（上线腾讯云按 D10 推迟到下一轮）。

## 1. 本阶段目标

补上唯一剩下的 MVP 能力——**语音转文字**，并把全站打磨到可交付：多宽度布局、真机可用、Lint/类型/测试全清。

## 2. 范围

### 本阶段包含
- **语音输入（R02/R03）**：输入区加麦克风按钮，用浏览器 Web Speech API 把语音转成文字填入输入框；不支持/拒绝麦克风/识别失败时**回退文字输入**，并给清晰提示；
- **响应式打磨**：360 / 390 / 430 / 768 / 1280 / 1440px 宽度逐个检查；长文本不溢出、输入区不遮挡内容、矮窗口可用；
- **真机验证**：手机浏览器走一遍核心流程（登录→记录→纠错→提醒→摘要→照片→周回顾），含键盘弹起；
- **发布准备**：清理 Lint/类型/测试/Console，更新 README，输出发布说明与已知问题。

### 本阶段不包含
- 云端 ASR（语音用浏览器本地识别，符合 PRD §6）；
- 自动周回顾、短信、OCR、删除、真实外发（均为二期/已定不做）；
- 腾讯云上线（D10 推迟下一轮）。

## 3. 用户流程

打开 → 登录 → 点麦克风说话 → 语音转文字填入输入框 → 发送；语音不可用时回退打字。核心闭环同阶段 3-1。

## 4. 页面状态矩阵

| 状态 | 对话工作台 | 语音输入 |
| --- | --- | --- |
| 加载中 | 消息提交 loading | 录音中（监听中） |
| 空 | 欢迎引导 | 未录音 |
| 成功 | 回执气泡 | 识别结果填入输入框 |
| 失败 | 提交失败可重发 | 识别失败/不支持 → 提示并回退打字 |
| 断线恢复 | 登录失效回登录页 | N/A |

## 5. 接口契约

- 语音纯前端（浏览器 Web Speech API），不新增后端接口；
- 复用现有全部接口，契约不变。

## 6. 实现方案

- 语音：封装 `useSpeechRecognition` 钩子，检测 `webkitSpeechRecognition` 可用性；不可用/报错时隐藏或禁用麦克风并提示"请用文字输入"；识别结果用 `onresult` 写入 textarea；
- 响应式：逐宽度用 Chrome headless 截图检查，修正溢出/遮挡；
- 发布：`npm run lint`、`npx tsc --noEmit`、`npm test`、`npm run build` 全过；README 补语音说明；证据包放发布说明。

## 7. 验收标准

- 语音：支持浏览器下说话能转文字；不支持/拒绝/失败时能回退打字并提示；中文识别可接受；
- 多宽度：390px 手机与 1280px 桌面布局正常，长文本不溢出，输入区不遮挡最后一条消息；
- `verify.sh PetPilot 阶段3-2` 五项全过；
- 产品经理手机真机走通核心流程。

## 8. 风险与回退

- 风险：Web Speech API 各浏览器支持不一、中文识别依赖浏览器/网络 → 按 PRD 约定"不保证全浏览器、失败回退文字"，如实记录；
- 回退：语音为独立钩子，出问题可整体关闭不影响文字输入。

## 9. 交付结果

- 语音输入 + 回退；多宽度与真机检查记录；发布说明；证据包（截图/照着做清单/是否表/verify 输出）。
