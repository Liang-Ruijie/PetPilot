# 第 2-3 阶段技术开发文档｜周回顾 + 全链路收口

> 配套文档：`docs/PRD/一页纸MVP.md`、`docs/PRD/宠物合伙人_MVP规则映射与提示词.md`、通用技术栈手册。
> 本文档只覆盖阶段 2-3。阶段 2 的最后一个子阶段，做完即后端 MVP 收口。

## 一、阶段目标

- **交付范围**：①周回顾（手动触发，不自动生成）②全链路收口冒烟 ③样例打分定 D2/D3 验收标准。
- **阶段产物**：周回顾接口 + 临时界面入口；收口冒烟记录；D2/D3 标准写入决策台账。
- **验收标准**（对齐 PRD §9 全部 5 条）：
  1. 一条命令起服务（已满足，收口再确认）；
  2. 真实 AI 自由输入走通：保存、纠错、提醒、历史查询、周回顾；
  3. 语音可回退文字（阶段 3 前端能力，本阶段 N/A）；
  4. 多猫不串、纠错不改错、提醒不误执行、重启数据还在；
  5. 产品经理能对着它 5 分钟讲清"这是个什么产品"。
- **明确不做**：自动周回顾（二期）、语音转文字（阶段3）、删除能力、真实外发/找医院、短信/OCR/COS。
- **本阶段打通的主链路片段**：登录 → 记录 → 分猫 → 纠错 → 提醒 → 就医摘要 → 照片 → 周回顾 → 历史查询（全链路收口）。

## 二、技术适配摘要

- 延续《技术适配声明》：后端先行 + 临时验收界面，FastAPI + SQLite + DeepSeek。
- 本阶段无新按需模块；周回顾复用 summary.py 的"汇总生成"模式。

## 三、技术栈与模型

- 复用 2-1/2-2 全部组件，无新增依赖。
- 周回顾：DeepSeek 一次调用，输入为近 7 天事实，输出叙述性周回顾（同就医摘要的生成模式）。

## 四、环境与配置

- 无新增环境变量、无新 Key。端口 8001 不变。

## 五、项目结构

```
backend/
├── app/
│   ├── api/weekly.py          新增：周回顾接口
│   ├── services/summary.py    复用并加周回顾 prompt
│   └── static/index.html      加"周回顾"按钮
├── migrations/versions/003_*.py  新增 weekly_reviews 表
└── tests/                     加周回顾测试
```

## 六、数据、资产与状态

- 新增表（003 迁移）：

| 表 | 字段 | 说明 |
| --- | --- | --- |
| weekly_reviews | id、pet_id(FK可空=全部猫)、title、fact_ids(JSON)、summary、created_at | 手动触发的周回顾；有内容才生成（R40） |

- 周回顾时间窗：近 7 天（`created_at >= now-7d`）；无记录时不生成并明确提示（R40"有内容才生成"）。

## 七、API 设计

| 方法 | 路径 | 说明 | 错误码 |
| --- | --- | --- | --- |
| POST | /api/weekly-review | `{"pet_id": 可选}` 手动触发周回顾 | WEEKLY_EMPTY（近7天无记录） |
| GET | /api/weekly-reviews | 列出周回顾 | — |

## 八、Prompt 设计

- 周回顾 prompt：同"就医摘要"风格，但要求"按时间回顾近 7 天变化、区分正常与值得关注、不诊断不处方、无内容则不编造"。

## 九、验收界面

- 临时界面加"生成周回顾"按钮（可选按猫）+ "查周回顾"查看区。

## 十、测试要求

- 第一层 mock：周回顾生成（有内容）；近 7 天无记录 → WEEKLY_EMPTY；回归 22 项不破坏。
- 第二层真实冒烟（收口）：真实 DeepSeek 全链路走一遍（登录→记录→分猫→纠错→提醒→摘要→照片→周回顾→历史查询），记录模型/耗时/结果。
- 样例打分：真实输入跑 5~10 条样例，交产品经理按维度打分，定 D2/D3 写入台账。

## 十一、验收清单（产品经理照着点）

- [ ] 点"生成周回顾"→ 看到近 7 天记录的叙述性回顾；
- [ ] 全新空库点"生成周回顾"→ 看到"近 7 天无记录"的明确提示（不编造）；
- [ ] 对真实样例打分（我会给你一份打分表）。

## 十二、风险与待确认项

- 风险：周回顾内容质量依赖事实数量，事实少则摘要薄 → 如实呈现，不编造。
- 待产品经理决定的问题：无（D2/D3 用样例打分在收口时定）。

## 十三、交接给下一阶段

- 阶段 3 正式前端直接复用全部后端能力：登录、分猫、纠错、提醒、就医摘要、照片、周回顾、历史查询；repository 层数据契约不变。
