# 第 3-1 阶段开发文档（前端）

> 配套：`docs/阶段文档/前端适配声明.md`、`docs/设计参考/PetPilot-MVP-视觉规范与修改提示词.md`、前端技术栈手册。
> 本阶段产出：正式前端工程（替换阶段 2 临时验收页），全部后端能力接入，含照片选猫归属。

## 1. 本阶段目标

用户打开网页，登录后能在一个符合 PetPilot MVP 视觉规范的主对话工作台里，完成"发消息记录 / 纠错 / 提醒 / 就医摘要 / 照片 / 周回顾"的完整闭环，桌面与移动端均可用。

## 2. 范围

### 本阶段包含
- 工程骨架：Vite + React + TypeScript（strict）+ Tailwind CSS（v4 `@theme` 设计变量）+ Lucide 图标 + Vitest；
- 设计变量：按 `PetPilot-MVP-视觉规范与修改提示词.md` 落地配色/字体/圆角/阴影/间距；
- 登录页（固定验证码 123456）；
- 主对话工作台：顶部品牌与建猫、宠物标签、消息流（用户蓝色气泡 + 助理回答直排）、底部输入区（一体圆角容器 + 箭头发送键）；
- 底部导航六视图：对话 / 记录 / 提醒 / 照片 / 摘要 / 周回顾，全部接真实后端接口；
- 照片上传：选猫归属 + 描述，只存原图+描述（无 OCR）；
- 登录失效自动清 token 回登录页。

### 本阶段不包含
- 移动端精细适配与真机键盘/安全区验证（阶段 3-2）；
- 流式输出、取消/重试等 Agent 高级交互（本产品对话为同步返回，暂不需要）；
- 语音转文字（阶段 3 前端能力，未接通前不呈现为可用）。

## 3. 用户流程

打开 → 登录（固定验证码）→ 建猫 → 底部输入一句话（或切到各视图操作）→ 看回执/结果 → 切"记录/提醒/照片/摘要/周回顾"查看详情。

## 4. 页面状态矩阵

| 状态 | 登录页 | 对话工作台 | 各列表视图 |
| --- | --- | --- | --- |
| 加载中 loading | 登录按钮 loading | 消息提交 loading | 列表加载 |
| 空 empty | N/A | 无消息时展示欢迎引导 | 各列表展示"暂无" |
| 成功 success | 跳转 | 显示回执气泡 | 展示数据 |
| 失败 error | 验证码错误提示 | 提交失败提示 + 可重发 | 加载失败提示 |
| 等待确认 | N/A | N/A | N/A |
| 断线恢复 | N/A | 登录失效自动回登录页 | 同左 |

## 5. 接口契约

- 复用后端全部接口：`/auth/login`、`/pets`、`/messages`、`/facts`、`/reminders/*`、`/photos`、`/care-summaries/*`、`/weekly-review`、`/weekly-reviews`；
- 统一错误结构 `{"error":{"code","message"}}`；`AUTH_REQUIRED` 时前端清 token 回登录页。

## 6. 实现方案

- 目录：`frontend/src/`（`api.ts` 集中 API 层 + `App.tsx` 主界面）；
- 设计变量集中定义在 `index.css` 的 `@theme`，一处改全站；
- 前端经 Vite proxy 转发 `/api` 到后端 8001。

## 7. 验收标准

- `npm run dev` 起前端，`npm test`、`npm run lint`、`npm run build` 通过；
- 桌面（1280px）与移动（390px）布局基本正确；
- 视觉符合 PetPilot-MVP 视觉规范；
- 六视图数据与后端一致，操作有回执，失败有提示。

## 8. 风险与回退

- 风险：视觉细节需打磨 → 只改设计变量与组件样式，不涉及后端；
- 回退：前端独立工程，可整体重做，不影响已验收的后端。

## 9. 交付结果

- 可运行的正式前端（替换阶段 2 临时页）；
- 全部后端能力的前端闭环；
- 代表页改前改后截图、照着做清单、是否表放入证据包。
