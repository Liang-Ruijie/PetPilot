# PetPilot MVP 一页纸（施工基线）

> 本文档是「宠物合伙人」MVP 的**唯一范围定义**。另两份文档（`砍留对照表.md`、`宠物合伙人_MVP规则映射与提示词.md`）与它保持一致；矛盾时以本文件为准。
> 旧项目「宠物合伙人-第三版」只作为规格与提示词来源；新 MVP **默认重写**，旧代码只作参考。
> 配套文件：`砍留对照表.md`（旧项目搬什么 / 丢什么）、`宠物合伙人_MVP规则映射与提示词.md`（R01–R80 映射 + 系统提示词 + schema）。

## 术语约定（先看这个）

- **本期不做（🚫）**：这轮明确不实现。
- **二期候选（⏸）**：只保留方向，**不代表承诺实施**。
- 旧功能编号（FR / R）仅用于追溯，本期只激活表格中标 ✅ 的部分。

## 1. 产品定位

猫主人的 Personal Agent：一个持续服务的助理，用一句话 / 一张照片 / 一段语音记录猫的日常，自动分清是哪只猫、记住它、在合适的时候主动提醒，并准备好就医时要说的摘要。

## 2. 一句话价值

> 主人随手说一句「明月今天吃了 26 克，明天上午九点提醒我看看贝塔」，助理自动分猫归档、设好提醒、到了就医时能给出有出处的准备摘要。

## 3. 唯一角色：只有主人端

- 医院端 / 公司端：**不做页面、不做登录、不做权限角色**。
- 就医准备之后，保留一个**由主人点击触发、明确标注「模拟」的医院回复**，只用于展示「摘要 → 医院回复」的流程衔接。它不是医院账号，不代表真实发送、接诊、预约或诊疗。

## 4. 核心闭环（5 分钟演示路径）

1. 验证码登录（固定验证码**仅用于合成体验空间**，不是真实客户登录方案）
2. 文字 / 照片 / 语音记录（照片**只存原图 + 主人描述**，不自动理解图片；语音=浏览器转文字，见 §6）
3. 多猫自动归属（明确表达优先，歧义才问，不串猫）
4. 记录/纠错有明确回执，事实带来源与出处（纠错需要原事实 + 版本 + 来源）
5. 生成就医准备摘要（**只生成，不真实外发**）；演示时可点击「模拟医院回复」按钮，看到一条明确标注模拟的回复
6. 设提醒 → 到期出现 → 可暂停/取消/反馈完成
7. 周回顾（**手动触发**，不自动生成）

## 5. 本期不做 & 二期候选

**本期不做（🚫）：**
- 医院前台完整页面、公司管理页面
- 真实短信 / 真实 OCR / 真实 ASR（云端）/ COS 云存储
- 医院报价与比较、到院凭证
- 删除能力（聊天删除、整猫删除等本期不实现；纠错保留）
- PG15 / Docker / 生产级部署验收（备份演练、监控、多实例、日志脱敏）

**二期候选（⏸，只保留方向）：**
- 报告原件上传与历史比较（FR05）
- 两层费用参考（FR11）、诊后资料与费用/退款核对（FR16）
- 找医院与真实外发（FR12 的真实外发部分）
- 脱敏分享卡（FR17）、知识发布/有来源的专业内容
- 周回顾自动生成（MVP 先手动）

## 6. 通道策略

| 能力 | MVP 做法 |
|---|---|
| 模型（AI） | 开发/调试用 mock；**验收必须真实 AI 自由输入走通核心闭环**；真实调用遵守另行批准的预算，文档确认 ≠ 自动获得调用授权 |
| 语音转文字 | 浏览器语音识别（Web Speech API 或所选方案）；效果依赖浏览器/网络，**不保证全浏览器支持或纯本地**；不支持/拒绝麦克风/识别失败时**回退文字输入**；中文识别效果列入验收 |
| 照片 | 只保存原图 + 主人提供的描述；**无 OCR、无报告解析、无多模态** |
| 登录 | 固定验证码，仅用于合成体验空间 |
| 短信 / OCR / ASR / COS | 全部不用 |

## 7. 技术形态

- 前端：React + Vite + TS
- 后端：FastAPI + SQLite（数据量小，不上 PG）
- 数据库迁移：1–2 个，不搬旧项目 27 个迁移
- 路由：约 10 个（登录、宠物、消息/记录、归属、摘要、提醒/任务、周回顾、演示空间），不搬旧项目 78 个

## 8. 部署（收口后再说，不卡验收）

- **本机稳定运行 + 能面试演示 = 本期收口条件。**
- 远程 URL / 腾讯云部署：**后续待核实**，不作本轮必须完成，也不在本轮开展。
- 免费套餐的存在 ≠ FastAPI / SQLite / 附件持久化 / 提醒调度已适配，**不承诺零成本必然部署成功**。

## 9. 成功标准（做到这 5 条 = MVP 收口）

1. 一条命令起服务，本机核心闭环走通
2. **真实 AI 自由输入**能走通：保存、纠错、提醒、历史查询（mock 仅用于开发验证，不用于宣布完成）
3. 语音转文字可用；不支持/拒绝/失败时能回退文字；中文识别效果达标
4. 多猫不串、纠错不改错、提醒不误执行、重启后数据还在
5. 你能对着它 5 分钟讲清楚「这是个什么产品」
