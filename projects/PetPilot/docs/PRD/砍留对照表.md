# 砍留对照表（旧项目 → 新 MVP）

> 用法：这张表回答两件事——
> 1. 旧项目的**功能**（FR01–FR20）哪些进 MVP、哪些二期候选、哪些本期不做；
> 2. 旧项目的**代码**哪些可作参考、哪些候选复用、哪些不搬。
>
> 原则：**只搬知识，不搬广度。** 新 MVP **默认重写**，旧代码只作参考；只有边界清楚、不依赖旧数据库和旧工作流的小段逻辑，经依赖检查与验证后才可**候选复用**，否则重写。

## 术语

- **本期不做（🚫）**：这轮不实现。
- **二期候选（⏸）**：只保留方向，不代表承诺实施。
- **候选复用（🔄）**：不是"直接搬"，须先做依赖检查 + 验证，无法独立复用就放弃。
