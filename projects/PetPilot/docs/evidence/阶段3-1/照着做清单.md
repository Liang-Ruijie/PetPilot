# 照着做清单｜阶段 3-1（正式前端·可运行骨架 + 完整闭环）

## 准备（两个服务都要起）

1. 后端：终端进 `backend` 目录执行 `bash run.sh`（端口 8001）。
2. 前端：另开一个终端进 `frontend` 目录执行 `npm run dev`（端口 5173，被占用会提示用 5174 等）。
3. 浏览器打开前端地址（如 `http://localhost:5174/`），验证码 `123456` 登录。

## 照着点

1. 登录后看到对话工作台（顶部 PetPilot、底部输入框 + 底部导航栏）。
2. 点右上「建猫」建两只：明月、贝塔。
3. 底部输入框发 `明月今天吃了 40 克，贝塔有点拉稀` → 看到右侧蓝色气泡（你的消息）+ 左侧回执。
4. 底部导航点「记录」→ 看到刚才归档的两条记录（带版本、出处）。
5. 发 `明天上午九点提醒我给明月称重`，点「提醒」→ 看到提醒，可点「完成/暂停/取消」。
6. 点「照片」→「上传照片」选一张图 + 描述 → 列表出现照片。
7. 发 `帮我整理贝塔的就医摘要，先不要发`，点「摘要」→ 看到摘要，点「模拟医院回复」。
8. 点「周回顾」→「生成周回顾」→ 看到近 7 天回顾。

## 看到什么算对

- 各视图数据与后端一致；操作有回执；失败有红色提示；登录失效自动回登录页。
- 手机宽度（≤390px）和桌面宽度布局都正常。

## 说明

- 前端是正式界面（替换阶段 2 临时页），风格按 PetPilot-MVP 视觉规范。
- 若某步报错，截图发我。
