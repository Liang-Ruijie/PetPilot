# 照着做清单｜阶段 2-3（周回顾 + 收口）

## 准备

1. 打开终端，进入 `backend` 目录执行 `bash run.sh`（窗口别关）。
2. 浏览器打开 `http://localhost:8001/`，验证码 `123456` 登录。
3. 建两只猫：明月、贝塔，再发几条记录（如 `明月今天吃了 40 克`、`贝塔有点拉稀`）。

## 照着点

**① 周回顾（本阶段新增）**
1. 点「生成周回顾」→ 看到一段按时间汇总近 7 天记录的叙述性回顾。
2. 点「查周回顾」→ 看到刚生成的周回顾。

**② 空库不编造**
- 刚登录、还没发过任何记录时，点「生成周回顾」→ 看到"近 7 天无记录"的明确提示（**不会编造内容**）。

**③ 全链路走一遍（收口，可选，2-1/2-2 已验过大部分）**
- 依次发：记录 → 纠错 → 提醒 → 就医摘要，上传照片，生成周回顾，最后「查记录」确认都在。

## 看到什么算对

- 周回顾只陈述已有记录，不编造、不下诊断；
- 空库生成周回顾 → 明确提示无记录；
- 全链路各步骤回执正确，历史查询能看到全部数据。
