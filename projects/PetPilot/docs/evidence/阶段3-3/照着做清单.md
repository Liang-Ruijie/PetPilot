# 照着做清单｜阶段 3-3（聊天输入统一改版）

## 准备

后端 `bash backend/run.sh`、前端 `npm run dev -- --host`，打开前端地址，验证码 `123456` 登录，建 2 只猫（如明月、贝塔）。

## 照着点

**① 输入框两态**
1. 初始：底部是单行胶囊——左麦克风、中"发消息或按住说话…"、右＋，**没有发送按钮**；
2. 点输入框：展开成编辑区，出现文字输入框 + 发送按钮；空草稿时发送置灰；
3. 输入文字：发送按钮变蓝点亮。

**② 按住说话**
- 按住麦克风说话，松开 → 语音转成文字进草稿，可编辑后再发送；（HTTP 环境会提示"语音不可用"，属正常回退）

**③ 照片进消息**
1. 点＋ → 出现「拍照」「照片」；
2. 点「照片」选图（可多选）；点「拍照」调相机（手机）；
3. 缩略图横向排列，每张右上角可移除；最多 5 张，超限有提示；
4. 打字 + 选图后点发送 → 一条消息（图在上、文字在下）。

**④ 照片归属**
1. 发"明月拉稀了" + 2 张图 → 文字和照片都归明月；
2. 只发图（不写字）→ 助手追问"有 N 张照片还不确定是哪只猫的"；
3. 回答"刚才那几张是明月的"→ 照片补归到明月。

**⑤ 回到底部**
- 发消息后上翻历史 → 输入框上方出现"↓"；点它回最新。

## 看到什么算对

- 输入框两态正确、发送按内容亮/灰；
- 照片随消息发送、刷新后仍在原位置；
- 照片归属与补归属正确；
- 底部已无「照片」Tab。

## 说明

- 分组归属（"前两张明月后三张团团"）本阶段按"无法唯一归属"挂起追问，不误归。
