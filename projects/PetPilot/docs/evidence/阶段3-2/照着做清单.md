# 照着做清单｜阶段 3-2（语音 + 响应式 + 发布准备）

## 准备

1. 后端 `bash backend/run.sh`，前端 `npm run dev`，打开前端地址，验证码 `123456` 登录。

## 照着点

**① 语音输入**
1. 看底部输入框左侧是否有一个**麦克风**按钮；
2. 点麦克风，对着说一句（如"明月今天吃了 26 克"）→ 识别出的文字应填入输入框，再点发送；
3. 如果浏览器不支持/拒绝麦克风/识别失败 → 应提示"语音识别失败，请用文字输入"，**并仍能正常打字**。

**② 响应式（手机 + 电脑）**
1. 用手机浏览器打开前端地址，走一遍：登录→记录→纠错→提醒→摘要→照片→周回顾；
2. 重点看：消息不溢出屏幕、底部输入框始终可见、键盘弹起时输入框不被挡住；
3. 电脑浏览器缩到窄窗口（约 390px）也正常。

**③ 长文本**
- 发一句很长的记录，确认不会横向溢出、不会截断。

## 看到什么算对

- 语音能转文字；不能转时能回退打字；
- 手机和电脑宽度下布局正常、输入框固定、内容不溢出；
- 各操作回执正确。

## 说明

- 语音是浏览器本地识别（Web Speech API），效果依赖浏览器/网络，不保证所有浏览器都支持——这是 PRD 约定，失败就回退文字。
