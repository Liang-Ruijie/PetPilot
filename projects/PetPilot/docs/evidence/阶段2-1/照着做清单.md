# 照着做清单｜阶段 2-1

> 本阶段用 mock 跑通文字记录闭环，**不需要 DeepSeek Key**。真实模型冒烟在收口阶段（需提供 Key）。

## 你需要的

- 一台 Mac（Python 3.12 已就绪）
- 一个浏览器（Chrome / Safari 都行）

## 照着点（每步后面写了"看到什么算对"）

1. 打开终端，进入项目 `backend` 目录，执行：
   ```
   bash run.sh
   ```
   - 看到 `Uvicorn running on http://127.0.0.1:8001` 就算起来了（端口 8000 被其他项目占用，本产品用 8001）。

2. 打开浏览器，访问 `http://localhost:8001/`。
   - 看到一个"PetPilot 临时验收界面"的登录框。

3. 输入验证码 `123456`，点「登录」。
   - 出现"建猫"输入框和聊天框。

4. 建两只猫：在"新猫名字"输入 `明月` 点「建猫」，再输入 `贝塔` 点「建猫」。
   - 上方出现两个标签：`1. 明月`、`2. 贝塔`。

5. 发第一句话：输入 `明月今天吃了 26 克，贝塔有点拉稀`，点「发送」。
   - 看到回执"已保存 2 条记录"，且 ✅ 两条分别归到"明月"和"贝塔"。

6. 验证不串猫：输入 `明月有点拉稀`，点「发送」。
   - 这条记录仍归"明月"，不会跑到"贝塔"。

7. 验证歧义挂起：输入 `贝塔2 有点拉稀`，点「发送」。
   - 看到 ⚠️"归属未知"，不乱记到"贝塔"。

8. 查记录：点「查记录」。
   - 看到之前的记录，每条带出处原文。

9. 验证重启不丢：回到终端按 `Ctrl+C` 停掉服务，再执行 `bash run.sh`，刷新浏览器页面。
   - 之前建的猫和记录都还在。

## 说明

- 本阶段界面是**临时验收界面**（阶段 3 会换成正式前端），只支持文字；照片/语音在后续阶段。
- 若某步报错，把屏幕上红色的错误文字截图发我。
